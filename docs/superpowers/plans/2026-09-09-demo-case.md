# Demo Case Jira + OpenRouter Laguna Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** El botón de demo pega un Jira vago de Cyber Monday; el sidebar muestra la respuesta del segundo turno para copiar; el writer live usa Laguna en OpenRouter y, si el schema falla, reintenta una vez con Nemotron.

**Architecture:** El arco no cambia (retriever → intake → writer). El ticket y la respuesta viven en `scoring.py`. OpenRouter sigue con un SKU por rol: supervisor = Nemotron, writer = Laguna. `writer_turn` recibe `fallback_llm` (Nemotron) y lo usa solo si `with_structured_output(SpecDocument)` levanta. `build_graph` cablea ese fallback cuando arma los modelos de la factory.

**Tech Stack:** Python 3.12+, pytest, Streamlit, LangChain `with_structured_output`, OpenRouter (`ChatOpenRouter`).

**Spec:** `docs/superpowers/specs/2026-09-09-demo-case-design.md`

## Global Constraints

- Identificadores en inglés. Comentarios en español.
- No tocar ranking, corpus, retriever, API ni la forma del grafo.
- El ticket de demo no puede tener dígitos ni las palabras de la tabla de huecos del spec (`buyer`, `pm`, `todos`, `solo`, `segundos`, etc.).
- Un solo botón pega el ticket. La respuesta se copia a mano; no agregar botón que la envíe.
- `LLM_PROVIDER=openrouter`. Supervisor: `nvidia/nemotron-3-ultra-550b-a55b:free`. Writer: `poolside/laguna-s-2.1:free`. Fallback del writer: el mismo Nemotron, una vez. Supervisor sin Laguna y sin fallback extra.
- No leer `.env`. La clave la pone el humano.
- Cerrar es del humano.
- Commits en `spec-refinery/` (cwd del repo).

```python
def _draft_from_llm(llm: BaseChatModel, ticket: str, human_lines: list[str], prior_text: str, citations, questions) -> SpecDocument:
    pm_block = "\n".join(f"- {line}" for line in human_lines) if human_lines else "(ninguno)"
    return llm.with_structured_output(SpecDocument).invoke(
        [
            SystemMessage(content=WRITER_PROMPT),
            HumanMessage(
                content=(
                    f"Ticket: {ticket}\n"
                    f"Mensajes del PM:\n{pm_block}\n"
                    f"Spec anterior:\n{prior_text}\n"
                    f"Citations: {[c.document_id for c in citations]}\n"
                    f"Preguntas: {questions}"
                )
            ),
        ]
    )


def writer_turn(
    state: RefineryState,
    llm: BaseChatModel | None = None,
    fallback_llm: BaseChatModel | None = None,
) -> dict:
    ticket = state.get("ticket") or ""
    close_requested = bool(state.get("close_requested"))
    citations = state.get("citations") or []
    questions = state.get("questions") or []
    spec = state.get("spec") or empty_spec(ticket)
    vaguedad = vaguedad_score(ticket)

    if llm is None:
        spec.pedido = ticket
        spec.choques = list(citations)
        spec.preguntas = [] if close_requested else list(questions)
        spec.estado = SpecStatus(
            se_puede_cerrar=close_requested and vaguedad == 0,
            vaguedad=vaguedad,
            razon="sin LLM",
        )
    else:
        human_lines = _human_texts(state.get("messages") or [])
        prior = state.get("spec")
        prior_text = prior.model_dump_json(indent=2) if prior is not None else "(ninguna)"
        try:
            draft = _draft_from_llm(
                llm, ticket, human_lines, prior_text, citations, questions
            )
        except Exception:
            if fallback_llm is None:
                raise
            draft = _draft_from_llm(
                fallback_llm, ticket, human_lines, prior_text, citations, questions
            )
        spec = draft
        spec.pedido = ticket
        spec.choques = list(citations)
        spec.preguntas = [] if close_requested else list(questions)
        spec.estado = SpecStatus(
            se_puede_cerrar=close_requested and vaguedad == 0,
            vaguedad=vaguedad,
            razon="writer",
        )

    return {
        "spec": spec,
        "messages": [AIMessage(content="Spec actualizada", name="writer")],
        "last_agent": "writer",
    }


def make_writer_node(
    llm: BaseChatModel | None = None,
    fallback_llm: BaseChatModel | None = None,
):
    def writer_node(state: RefineryState) -> dict:
        return writer_turn(state, llm, fallback_llm=fallback_llm)

    return writer_node
```
